# Concurso de Precios - Grupo 7

## Ejecución

Necesitas Python 3. Abre el proyecto en VS Code y ejecuta `juego.py` con el botón **Run Python File**. También puedes abrir una terminal en la carpeta del proyecto y ejecutar:

```powershell
python juego.py
```

Se abrirá una ventana gráfica hecha con Turtle. Elige la cantidad de jugadores con el mouse; haz clic en el campo de texto para escribir nombres y precios, y presiona Enter para confirmar. Mantén `juego.py` y `algoritmos.py` en la misma carpeta.

## Archivos `__pycache__`

Python crea automáticamente esta carpeta al importar o ejecutar archivos `.py`. Contiene archivos `.pyc` con bytecode compilado para acelerar futuras ejecuciones. No son el código fuente, no hace falta editarlos y se pueden borrar: Python los volverá a generar cuando sean necesarios.
